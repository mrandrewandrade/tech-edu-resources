# Colour palette choices

The active colours are in `_brand.yml`. Copy one complete `color:` block below
over the active `color:` block, save, and run `quarto preview` again. These
palettes use dark foreground colours on light backgrounds and were selected as
accessible starting points. Always check your own changes with a contrast tool.

## Harbour

```yaml
color:
  palette:
    ink: "#18232A"
    paper: "#FFFFFF"
    navy: "#173A51"
    blue: "#166B86"
    gold: "#B57400"
    mist: "#EAF4F6"
  background: paper
  foreground: ink
  primary: blue
  secondary: navy
  warning: gold
  light: mist
```

## Circuit purple

```yaml
color:
  palette:
    ink: "#241E2B"
    paper: "#FFFFFF"
    purple: "#654087"
    plum: "#463052"
    amber: "#9A5D00"
    mist: "#F3EEF8"
  background: paper
  foreground: ink
  primary: purple
  secondary: plum
  warning: amber
  light: mist
```

Do not use colour alone to communicate pass/fail, polarity, warning, or status.
Keep words, symbols, or patterns alongside colour.

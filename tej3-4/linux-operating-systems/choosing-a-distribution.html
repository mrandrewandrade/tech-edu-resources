Choosing a Linux Distribution

Compare Linux distributions and explain why this class uses Linux Mint Xfce.

Different flavours of Linux

A Linux distribution, or distro, is a complete operating system built around Linux. Distros are a little like different flavours: they share many ingredients, but each has its own installer, desktop, software choices, update system, and community. No flavour is best for everyone, although people often have strong preferences. Some distributions are also based on other distributions.

For example:

Debian
└── Ubuntu
    ├── Linux Mint
    └── Lubuntu

Debian is a long-running, community-built distribution known for stability. Ubuntu is based on Debian and aims to make Linux practical for a wide range of users. The African word ubuntu is often translated as “I am because we are.” Linux Mint is a child of Ubuntu: it uses Ubuntu as a foundation and adds its own desktop experience and tools.

Our choice: Linux Mint Xfce

We will use Linux Mint 22.3 “Zena” Xfce Edition because it works well and is easy for students to begin using. Xfce is the desktop interface. Its layout feels a little like older versions of Windows, and it runs quickly on our older computers with less than 8 GB of RAM. It starts simple, but we can improve and personalize the way it looks later.

Lubuntu is another good lightweight flavour to explore. If you want to compare many possibilities, try the questions at Distrochooser.

Release styles: a stable base or the newest software

Ubuntu publishes a new version every six months, usually in April and October. Its version number shows the year and month: 24.04 means April 2024. Releases also have names, such as Ubuntu 24.04 “Noble Numbat.”

Every two years, the April release is an LTS, or Long Term Support, release. LTS versions receive updates for much longer than the releases between them, making them a dependable base for a classroom or everyday computer. Linux Mint 22.3 “Zena” uses the Ubuntu 24.04 LTS package base and is supported until April 2029. We can keep an LTS-based system for work and experiment with a faster-moving distribution on another computer, in a virtual machine, or later as part of a dual-boot setup.

Arch uses a rolling-release model instead of publishing separate LTS versions on a fixed timetable. You install it once and update it continuously, so new software arrives quickly. This gives you current software and a great deal of control, but it also asks you to read update notices, make decisions, and troubleshoot more often.

Arch Linux is the most difficult option discussed here. It expects you to assemble and configure much more of the system yourself. That makes it a poor first classroom installation, but a valuable future challenge if you want to become a system administrator and understand or control every part of a Linux system.

In my classes, students who chose Arch and persisted through its difficulties have often gone on to considerable success in computer engineering, including major scholarship and job opportunities. Arch itself is not a shortcut to those outcomes. The persistence, research, troubleshooting, and systems thinking required to make it work are excellent preparation.

For this lab, our choice is Linux Mint Xfce. In a future lab, we will choose another operating system and install it alongside Windows to create a dual-boot computer.

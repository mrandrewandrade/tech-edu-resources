5. Circuits and Electronics5 lessons
1. Package 1: Basic Electricity and Parallel Circuits▾

Connect basic electrical quantities, components, measurement, computer loads, and parallel-circuit calculations.

Parallel paths explain why loads in computers, vehicles, and buildings operate independently.

2. Package 2: Parallel Review and Series Circuits▾

Review one parallel calculation, then calculate current, voltage drops, resistance, and power in one-path circuits.

Series rules appear in indicator lights, sensor chains, voltage drops, and component strings.

3. Series-Parallel Circuits▾

Reduce mixed networks in stages and verify currents and voltages.

Real systems often combine shared paths with parallel loads.

Write current and voltage equations for circuits that cannot be reduced directly.

7. Linux and Operating Systems12 lessons
1. Choosing a Linux Distribution▾

Compare distribution families, desktop environments, hardware needs, software, and support.

A good choice matches the computer and the work instead of following a brand name.

2. Install Linux Mint▾

The activities build confidence before students administer or program the system.

4. Know Your Linux Computer▾

Record hardware, operating-system, storage, and device information.

5. Files, Terminal, and Permissions▾

Navigate paths, inspect files, and use permissions safely.

These skills are essential for administration, automation, and development.

6. Git Version Control▾

Record, inspect, and share changes with a safe Git workflow.

7. Build a Quarto Website▾

Turn Markdown, code, and media into a small technical website.

8. Publish with GitHub Pages▾

9. Python Measurement Logging▾

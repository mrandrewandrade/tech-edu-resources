# Logo stamp production notes

This file records the approved student workflow for the logo-stamp lesson and is the source of truth for future screenshots and written instructions.

## Approved student workflow

1. Open or create the original artwork in Photopea.
2. Keep the original bitmap on a locked reference layer.
3. Build clean vector artwork with named Shape layers. Students may use **Image > Vectorize Bitmap** as a starting point, then simplify and repair the paths.
4. Convert text to shapes and remove the background and any unwanted regions.
5. Test the design as a single-colour silhouette. Required holes and gaps must remain open.
6. Export the vector artwork from Photopea as SVG. Do not describe Photopea as exporting DXF directly.
7. Upload the SVG to the Technology Commons stamp-preparation tool.
8. In the tool, set the stamp diameter, edge margin and mirror direction; review path-validation warnings and the final impression preview.
9. Download the centred, scaled, mirrored, millimetre-based DXF.
10. In Onshape, sketch on the top face of the 4 mm backing, import the DXF at the file origin in millimetres and extrude the closed regions 2 mm with **Add**.
11. Inspect the model from the top, side and isometric views before exporting the STL.

The website tool is the bridge between Photopea's SVG export and Onshape's DXF sketch import. It should automate CAD file conversion and fabrication checks without replacing the student's layer, vector-path and design decisions.

## Tool requirements

- Accept SVG artwork.
- Preserve holes and interior cutouts.
- Flatten transforms and convert supported curves into valid DXF geometry.
- Detect open paths, detached islands and very small details.
- Let the student set stamp diameter and minimum edge margin.
- Centre and uniformly scale the artwork in millimetres.
- Mirror the stamping face left-to-right.
- Show both the stamp-face preview and the correctly oriented impression preview.
- Export an Onshape-ready DXF.

## Standard model values

- Stamp diameter: 38 mm
- Flat backing: 4 mm
- Raised logo relief: 2 mm
- Overall height: 6 mm
- Minimum edge margin: 3 mm
- Minimum stroke and gap: 1.2 mm
- Typical maximum logo extent: 30-32 mm

## Screenshot sequence

Capture real application states in this order:

1. Photopea document with the locked reference layer and named artwork layers visible.
2. Vectorized or manually built Shape layers with the background removed.
3. Clean single-colour artwork and visible holes/gaps at a useful zoom.
4. Photopea **Export As > SVG** action.
5. Website tool after SVG upload.
6. Tool settings showing 38 mm diameter, 3 mm margin and mirroring enabled.
7. Tool validation and stamp/impression previews.
8. DXF download action.
9. Onshape DXF import into a sketch on the backing's top face, using millimetres and the file origin.
10. Onshape top view showing centred mirrored geometry and the required margin.
11. Onshape side view showing the 4 mm backing plus 2 mm relief.
12. Onshape isometric proof with the variables and feature tree visible.

## Writing rules

- Teach why a stamp face must be mirrored, not only which button to press.
- Distinguish raster layers from vector Shape layers.
- State that SVG is the Photopea export and DXF is generated by the website tool.
- Explain that imported DXF geometry is not parametrically resized by later Onshape variable changes; generate a new DXF when the artwork size changes.
- Keep the backing flat and exclude handles from this mission.
- Use the student's own artwork and do not trace commercial logos.

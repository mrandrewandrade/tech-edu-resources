Learning Worlds lesson list

Central Hub

  • Technology Commons Hub - Start here. Choose the circuit-and-computing realm or the fabrication frontier.
  • Safety Gate - Pause before tools, power, heat, or moving equipment.
  • Mission Control - See the larger course route and choose the next useful mission.
  • Help and Search - Use the site search, glossary, classmates, documentation, and your teacher.
  • Portfolio Archive - Turn work into evidence: decisions, tests, photos, code, and reflection.

Circuit and Computing Realms

  • Circuit and Computing Realms - Enter TEJ to measure, build, compute, program, and document.
  • Measurement Meadow - Learn what voltage and current mean before placing a meter.
  • Ohm's Law Outpost - Connect voltage, current, and resistance using predictions and measurements.
  • Kirchhoff Canyons - Track current at junctions and voltage around complete loops.
  • Breadboard Bay - Move from a schematic to a simulated or physical circuit without guessing.
  • Series-Parallel Pass - Read paths and junctions before calculating an equivalent circuit.
  • Component Caverns - Explore resistors, diodes, transistors, op amps, and schematic symbols.
  • Capacitor Coast - Watch stored charge change voltage over time and shape circuit behaviour.
  • Linux Terminal Tower - Navigate files and use the terminal with deliberate, visible commands.
  • Python Plains - Use small Python programs to calculate, log, graph, and explain evidence.
  • BeagleBone Bridge - Connect Linux and Python to low-voltage inputs and outputs safely.
  • Project Portals - Combine a useful circuit, code, testing, and a story of improvement.
  • TEJ Portfolio Dock - Publish the evidence behind your circuits, code, tests, and decisions.

Fabrication Frontier

  • Fabrication Frontier - Enter TAS to investigate, design, fabricate, test, and improve.
  • Design Process Plaza - Start with a situation and user need, not a favourite tool or first idea.
  • Sketching Slopes - Make ideas visible so they can be discussed, measured, and improved.
  • Digital Design District - Build clear raster, vector, layout, animation, and interface assets.
  • CAD Citadel - Model with dimensions and relationships that can survive a change.
  • Materials Forest - Match material properties and tolerances to the process and purpose.
  • Hand Tool Harbour - Select, inspect, carry, use, and store tools safely.
  • Laser Labyrinth - Prepare clean vector geometry, test material settings, and assemble accurately.
  • 3D Print Peaks - Design for layers, orientation, support, tolerance, and useful iteration.
  • Prototype Yard - Build the smallest useful model that can answer one important question.
  • Testing Works - Compare the result with the success criteria and improve from evidence.
  • Fabrication Missions - Choose or propose a project that proves design, making, testing, and communication.
  • TAS Portfolio Dock - Publish the story behind the need, design choices, making, tests, and changes.

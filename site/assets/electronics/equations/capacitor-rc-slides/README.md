# Capacitor and RC slide equations

`capacitor-rc-equations.tex` is the canonical source for the equation images used in the three capacitor and RC teaching decks. Run `render-assets.ps1` to rebuild the tightly cropped transparent PNG files. The script uses a worktree-local Matplotlib install because the system MiKTeX setup is incomplete. The website and Jupyter notebooks use the same LaTeX directly in Markdown.

TECHNOLOGY COMMONS NAME TAG DESIGN PACK

Canvas: 11 x 4 in at 300 ppi
Automatic raster size: 3300 x 1200 px
Safe margin: 0.25 in on every edge
Typeface: Source Sans 3 Bold, all caps
Alignment: logo and name share one horizontal centreline; centre the complete group vertically

VARIATION 1
Technology Commons emblem + A. ANDRADE
Clear and professional. The abbreviated first name preserves room for large letters.

VARIATION 2
Small Technology Commons emblem + ANDRADE
Best distance readability. The name receives almost all available width.

VARIATION 3
Technology Commons emblem + thick AA lettermark + NDRADE
Most personal. The AA mark is thickened by 18 px so it survives engraving and reads as the first A.

Each PSD is 11 x 4 in at 300 ppi and contains separate named artwork layers. The matching PNG is a clean full-size reference/export. Open the PSD in Photopea or Photoshop, select the name layer, replace the text, and recheck the 0.25 in safe margin. If a font substitution warning appears, choose Source Sans 3 Bold from Google Fonts.

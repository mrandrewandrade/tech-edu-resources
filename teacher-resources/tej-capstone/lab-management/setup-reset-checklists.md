# Capstone Lab Setup, Reset, and Close Checklists

## Teacher setup before the rotation begins

- [ ] Confirm emergency shutdown and protected supply settings.
- [ ] Test every active controller, meter, reference circuit, relay/lamp station, and quiet buzzer.
- [ ] Keep the horn station teacher-controlled and disconnected until used.
- [ ] Place exact pin maps/datasheets with the matching hardware.
- [ ] Put a known-good reference component at diagnostic stations.
- [ ] Count parts into labelled station bins.
- [ ] Separate spare, rejected, and untested components.
- [ ] Open the Linux simulator/test files on S1 computers where practical.
- [ ] Verify S6 portfolio files can be edited/rendered or provide an offline alternative.
- [ ] Display rotation assignments and required evidence.

## Team entry check

- [ ] Read the station goal before touching equipment.
- [ ] Inspect/count the station and report existing damage immediately.
- [ ] Write a prediction or test goal.
- [ ] Identify who controls power and who records evidence.
- [ ] Confirm teacher approval state before energizing.

## Powered-station check

- [ ] Schematic matches the physical version.
- [ ] Source voltage/current limit/fuse is correct.
- [ ] Polarity, pinout, resistor, driver, diode, and ground are checked.
- [ ] Meter mode/range/jacks are checked.
- [ ] Hands/tools are clear before power on.
- [ ] Stop for heat, smell, smoke, noise, current limiting, unstable supply, or unexpected operation.

## Reset before transition

- [ ] Stop Python safely and save files/logs.
- [ ] Switch off and disconnect external load power.
- [ ] Discharge approved capacitors through the intended path.
- [ ] Return meter to voltage mode with leads in COM and V/ohm.
- [ ] Restore the trainer/reference fault state specified by the teacher.
- [ ] Count parts, leads, and adapters.
- [ ] Place damaged/suspect parts in the reject container with a note.
- [ ] Remove personal files/account sessions from shared equipment.
- [ ] Wipe the workspace and keep conductors untangled.

## End-of-class team exit

- [ ] Design log has a dated, specific entry.
- [ ] Evidence file names identify the project without private student numbers.
- [ ] Team can state what worked, what remains uncertain, and the next test.
- [ ] Components are returned to the correct labelled bin.
- [ ] Controller, meter, source, and station identifiers are signed back in.
- [ ] Teacher or station lead confirms reset before dismissal.

## Teacher close

- [ ] All load supplies and horn station are disconnected.
- [ ] Controllers are shut down or left in the approved state.
- [ ] Meter leads/jacks/modes and fuses are checked as needed.
- [ ] Missing/damaged stock is entered in reconciliation.
- [ ] Batteries/power supplies are placed in approved storage/charging state.
- [ ] Student evidence requiring follow-up is noted before the next class.
- [ ] Failed equipment is quarantined and labelled.

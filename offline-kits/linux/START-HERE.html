Start from the class USB

  1. Copy the ZIP to Downloads and extract it.
  2. Open this START-HERE.html file inside the extracted folder.
  3. Choose Computer Detective or Bashcrawl above.
  4. Use the ODT in LibreOffice, or use the PDF with the matching TXT answer sheet.

Do I need LibreOffice?

Linux Mint normally includes LibreOffice Writer. ODT is the best choice in LibreOffice, while DOCX also works. If Writer is unavailable, use the PDF for instructions and complete the matching plain-text answer sheet in Text Editor.

libreoffice --version

This kit does not include a portable office program. Do not run an unknown installer from a USB drive.

Run the correct appearance script

First identify the desktop. Cinnamon and Xfce use different settings, so do not force the wrong script to run.

echo "$XDG_CURRENT_DESKTOP"

Cinnamon: copy tej-cinnamon-style.sh to Downloads. It previews the preset, creates a backup, and includes Restore.

cd ~/Downloads
less tej-cinnamon-style.sh
chmod +x tej-cinnamon-style.sh
./tej-cinnamon-style.sh

Xfce: copy tej-xfce-style.sh to Downloads.

cd ~/Downloads
less tej-xfce-style.sh
chmod +x tej-xfce-style.sh
./tej-xfce-style.sh

Copy and start Bashcrawl

Copy the complete bashcrawl folder from this kit. In Files, open Home, create a folder named Games, and paste bashcrawl inside it. Hidden folders are part of the game, so copy the whole folder. Open Terminal with Ctrl + Alt + T.

cd ~/Games/bashcrawl/entrance
cat scroll

Chromebook

On a personal Chromebook or owner account, enable Settings > About ChromeOS > Developers > Linux development environment while Internet access is available. Open Terminal from the Launcher and move the complete bashcrawl folder into Linux files. A school-managed Chromebook may block Linux. Do not use Developer Mode to bypass that restriction.

Phone or tablet

Using a phone is slower and more difficult than using a computer, but it works. A Bluetooth keyboard makes the work easier. On Android, install Termux from F-Droid. On iPhone or iPad, install iSH Shell. Complete the initial app and package setup while Internet access is available.

If you are waiting for a classroom computer or Internet connection, use your phone to begin or continue the assignment instead of doing nothing.
